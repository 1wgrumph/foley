# Proof quality contracts

- `prove` retains `regression.test.mjs`, `proof.json`, existing statuses and attempt result fields. Accept target-native Vitest 3.0.6 alongside node-test, with the same confinement. For a hand-written known-good Vitest test supplied through the ordinary candidate contract, record a runner result with bug exitCode 0 and `wrong_predicate` (not verified). Preflight refuses unsupported runners with exit 2 and `unsupported_runner` before calls.
- A repeatable failing assertion without a known fixed build or independent predicate control is `not_verified`, reason `inconclusive`; never publish an accepted regression file. Model assertion labels and expected-value substrings are not independent controls. Retain the existing owned archive positive control and the unrelated/malformed test refusals. An independent control establishes predicate behavior on both builds using trusted target behavior, not candidate text.
- Predicate discriminant: `visible_text` uses nonempty CSS selector and distinct string expected/observed; `element_count` uses nonempty CSS selector and distinct nonnegative safe-integer expected/observed; `console_error` uses distinct boolean expected/observed and nonempty `message` (exact console error text); `canvas_state` uses `source` equal to `elements` or `appState`, `path` array of string keys or nonnegative indices, and distinct JSON scalar expected/observed values. Read only data from the target API (Excalidraw test hook `window.h.elements` / `window.h.state`); no model-supplied code. Unavailable data is not an observation. For console errors, capture actual page error-level console messages before navigation; `checkPredicate(page, predicate, {consoleErrors})` accepts these messages as strings.
- `validateSteps` and `validateRun` retain null for correct-behavior clips/incomplete runs, and reject unsupported/malformed or equal predicates. Watch returns `malformed_output` for malformed predicates; valid null may be recorded. Repro returns `not_reproduced`, observed false, empty attempts and a stopped event with reason `no_predicate` (null) or `malformed_output` (invalid), before a paid call.
- Repro reply: object with actions array and boolean done; when done, require verdict `reproduced` or `not_reproduced`; when not done verdict optional. Declared action objects require their action-specific selector/value/to_selector (as applicable); unknown action names are still dropped. Reject any malformed turn before its first action using stopped reason `malformed_output`, retaining explanation limits. Nonempty target not required for model actions.
- Steps and run documents optionally contain `uncertainty` and `narration_evidence`, each an array of at most 40 entries `{t_s, text}`; finite timestamp 0..120 and nonempty plain text at most 1024 characters. Preserve through watch, run, comment and replay. Absent narration need not create a field. Display both as plain text, with timestamps, using `data-testid="uncertainty"` and `data-testid="narration-evidence"`.
- Shared `src/text-safety.mjs` exports `hasCredentialShape(text)` (boolean); input and display retain their independent checks with identical current credential-shape policy. Existing paired refusal tests remain. This deduplication is structural: identical observable behavior on the old version cannot itself supply an honest behavioral red.
