# Location, evaluation and publication contracts

- BRAN CLI and anchors schema unchanged. At equal term-hit count, a file whose graph node matches a term ranks ahead of a nonmatching file, before lexical ordering. Invalid JSON number syntax exits 1 with a JSON diagnostic; valid JSON numbers retain ordinary term extraction.
- `foley eval` accepts the existing `--labels FILE` (default `fixtures/eval/held-out.json`) and the backlog target/media options. The fixed eight issue IDs in the committed held-out corpus are the only evaluation population; the tuning corpus must be disjoint. Refuse invalid, duplicate, substituted or tuning IDs with exit 2 and `bad_labels`, before calls. Select census rows by these IDs, not by existing backlog membership.
- `--max-issues 0` scores without new calls; absent held-out rows are explicit `eligible_not_attempted` rows with zero cost/time and no anchors. Preserve existing summary fields in `out/eval-report.json`; add `results` (the eight rows, held-out order, including anchors and elapsed_ms). No tuning row contributes to any metric. With new attempts, use the selected population only and retain rows for unattempted issues.
- `eval` accepts `--budget-usd` (default 1.50); `backlog` accepts `--budget-usd` (default 3.80) and `--per-issue-usd` (default 0.40, equivalent to existing integer case budget when supplied). Reject over-ceiling or invalid budgets with exit 2 and `budget_refused` before requests, including dry runs. Reconcile accumulated settled and booked costs against the authoritative ledger before spending. Never reserve beyond the remaining envelope or per-case budget. Existing `--dry-run` remains zero-call.
- Minimum Node version is 22.12.0: `package.json` engines and lock root agree; `tools/preflight-tools.sh` exits 1 with a diagnostic naming Node and 22.12.0 on an older version.
- Public check: `assignment-metadata` finding, exit 1, for private assignment lines in return files (including combined or individual harness/model/worktree/session fields). Generic attribution in Git metadata is excluded. Seeded negative control uses an isolated generated tree, not actual private metadata.
